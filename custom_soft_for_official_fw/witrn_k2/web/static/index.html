Підключення в різних ОС:

🪟 Windows: Драйвери не потрібні (використовується системний HID-драйвер). Якщо пристрій не розпізнається, переконайтеся, що офіційну програму WITRN закрито (вона блокує порт пристрою для інших програм).

🐧 Linux: Для доступу без прав root налаштуйте udev через setup_udev.sh або додайте правило:

SUBSYSTEM=="hidraw", ATTRS{idVendor}=="0716", ATTRS{idProduct}=="5060", MODE="0666", TAG+="uaccess"
SUBSYSTEM=="usb", ATTRS{idVendor}=="0716", ATTRS{idProduct}=="5060", MODE="0666", TAG+="uaccess"

Файл правил розташований у проекті: setup_udev.sh.
